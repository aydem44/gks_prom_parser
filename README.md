# Парсер данных Росстата по промышленному производству

Скрипт для автоматической выгрузки и обработки данных Росстата по промышленному производству из помесячных Excel-файлов. Собирает данные по кодам ОКПД 2 согласно заданному шаблону за указанный период.

## Возможности

- Автоматическая загрузка помесячных файлов Росстата с официального сайта
- Парсинг данных по различным классам ОКВЭД
- Извлечение значений по кодам ОКПД 2 из шаблона
- Гибкая настройка периода загрузки (через переменные окружения)
- Обработка ошибок и отсутствующих данных

## Установка

```bash
git clone https://github.com/yourusername/rosstat-parser.git
cd rosstat-parser
pip install -r requirements.txt
```

## Настройка
Создайте файл `data.env` со следующими параметрами:

```bash
MASK_FILE=путь/к/шаблону.xlsx    # Excel-шаблон с кодами ОКПД 2
OUTPUT_FILE=путь/к/результату.xlsx # Путь к выходному файлу
PERIODS=12                        # Количество месяцев для загрузки
```

## Структура шаблона
Excel-файл шаблона должен содержать:
- Столбец A: Без заголовка (индекс)
- Столбец B: Заголовок "Код ОКПД 2" (коды ОКПД 2)
- Столбец C: Заголовок "Товар" (наименования продуктов)
- Первые 2 цифры кода ОКПД 2 определяют класс ОКВЭД

## Результат
Итоговый Excel-файл содержит:

- Все столбцы из исходного шаблона
- Дополнительные столбцы для каждого месяца (в формате ММ_ГГГГ)
- Значения из файлов Росстата для каждого кода ОКПД 2 и месяца

## Обработка ошибок
Скрипт включает:

- Обработку таймаутов HTTP-запросов
- Проверку статуса ответа (обработка 404)
- Альтернативный формат для 7-значных кодов ОКПД 2
- Информирование о прогрессе выполнения

## Ограничения
- Требуется интернет-соединение для доступа к серверам Росстата
- Именование файлов соответствует структуре Росстата: Prom_ММ_ГГГГ.xlsx
- Формат листов: Н-П_XX (где XX - класс ОКВЭД)
